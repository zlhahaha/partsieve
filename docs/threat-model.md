# 威胁模型与业务配置边界

输入可控制ZIP、文件名、XML、关系、类型和嵌入数据。PartSieve不执行宏、不激活对象、不下载资源、不解析DTD和外部实体，不判断VBA代码是否恶意。它不是通用杀毒或Office解析器漏洞防护工具。

支持DOCX/DOCM与XLSX/XLSM的明确业务子集，处理已验证的VBA所有权集合。Word可额外移除一个settings本地、恰好一个attachedTemplate引用的HTTP(S)模板关系；同时删除源XML元素并验证其他设置不变。

拒绝损坏/超限、重复/等价名称、URI歧义、缺失目标、重复本地关系ID、错绑引用、未知类型/关系/命名空间/扩展、公式、未支持的链接协议/内部书签、外部图片/工作簿、Excel OLE、链接型/共享/未知OLE、ActiveX、签名、字段、浮动/未知图片、SVG/VML、加密和其他格式。共享宏依赖或保留XML引用待删宏也拒绝。

普通HTTP(S)点击超链接按来源局部XML绑定检查后保留；HTTP(S)允许不表示目标可信，程序不访问地址。一个Word正文内嵌CFB对象可移除，连同其独占PNG/JPEG/EMF预览和关系一起删除；仅在此删除子树中接受已建模VML，不执行对象或递归清理内容。其余正文进行语义及实际输出hash核验。

保留的图片检查类型、基础签名及来源局部引用，保留原始数据；不做完整图片格式校验、重编码或解码器漏洞防护。能打开、hash相同、格式通过均不能单独证明视觉完全一致或未知威胁不存在。

输入32MiB、输出64MiB、条目32MiB、累计解压128MiB、条目4096；单XML8MiB、深度128、节点200000、属性400000，包聚合节点/属性各1000000；关系/引用32768、文本/标记token65536 code units、单元素属性256。限额仍为实验值。解析未完成、资源拒绝为Incomplete，不能解释为没有禁止能力。

SDK接收bytes，读取前限额、硬超时/取消与发布由宿主负责。MoonBit原生CLI和内部worker均对常规文件有界读取，拒绝末端符号链接与非普通文件；CLI使用私有快照、16MiB报告管道上限和60秒worker超时。小型C层只封装系统调用。临时输出重读验证，独占发布不覆盖已有文件，两个路径不保证事务原子性。

报告绑定字节和版本，不提供真实性签名；可能包含输入中的外部目标证据，宿主应按文档访问要求管理。独立格式/客户端不在SDK内执行，返回NotChecked。WPS Word保存副本的样式顺序错误、资源规模校准和真实下游尚需后续验证。
