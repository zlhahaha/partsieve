# 0.6 保留契约

比较对象为解压后的内部文件原始数据，不是整个ZIP容器字节。

| 对象 | 分类 | 核验 |
| --- | --- | --- |
| 支持的VBA、专属配套信息及受控Word OLE载荷/专属预览 | RemovedByPolicy | 类型、所有者、引用和删除范围一致，输出中不存在 |
| VBA/OLE主关系、Content Types及模板设置关系文件 | RegeneratedMetadata | 等于从原件独立计算的预期修改，只删除已支持关系并转换主类型 |
| 有外部模板的Word settings XML | SemanticallyRewritten | 只移除一个已验证attachedTemplate，展开名称/属性值/深度/文本逐项比较，其余设置不变 |
| 有受控OLE的Word主文档XML | SemanticallyRewritten | 删除整个已验证inline对象子树，其他展开名称、属性、深度与文本语义不变；正常表格、图片与链接不被授权删除 |
| 其余正常内容、图片、工作表、表格、样式、页眉页脚 | BytePreserved | 每个内部文件SHA-256相同，不允许额外新增、删除或改动 |

验证从实际原件/输出重算完整图、文件集合和hash。外部计划绑定原件、全部内部文件、限制、决策和依赖，每个字段必须独立重算一致。模板先修改设置XML，再移除关系、重建关系文件；操作带明确依赖和预期hash。

VBA为隐式关联，保留XML不允许引用待删宏或配套信息；共享依赖拒绝。日期系统、数值、样式关联、文本和工作表保留；样式/共享字符串索引越界拒绝。图片限定受支持内嵌PNG/JPEG，数据原样保留，不提供图像解码安全鉴定。未知内容不自动删除，不按引用可达性进行全包清理。

普通HTTP(S)点击链接按来源局部引用保留，目标不访问；其能力作为allowed_capabilities单列，不能把允许的点击目标冒充成禁止能力已全部消失。受控OLE对象及其独占PNG/JPEG/EMF预览整体删除，预览内容与对象编辑能力明确丢失。共享、链接型、多对象与未知结构拒绝。

独立格式/客户端检查在SDK中NotChecked，不能继承历史Pass。无原件则保留检查NotChecked、整体Incomplete。Schema仅约束形状；原件/输出/报告要重新核验一致。0.6报告绑定新的工具、规则与业务配置，旧报告应使用对应版本或基于真实文件重新生成。

CLI有界读取、临时输出重读后配套发布，不覆盖目标；两个路径不保证事务原子性。hash不是签名。资源数值仍为实验值，SDK通过WorkControl共享工作预算并协作取消；超限/取消不返回成功产物，计费单位不代表完整内存或耗时保证，见[资源预算](resources.md)。

WPS保存副本由客户端重写；当前Word副本能编辑和重开，但有三处样式顺序错误。原始输出格式通过不能替代保存副本结果，也不等于通用Office安全或视觉完全一致。
