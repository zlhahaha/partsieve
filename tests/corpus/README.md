# Native regression corpus

`commands.json` describes 293 public CLI invocations; `commands.zip` holds 223
content-addressed input/file-state blobs (about 1.4 MB compressed). Native tests
in `tests/native/native_test.mbt` unpack them with explicit limits, verify each
blob's SHA-256, invoke the actual bounded CLI, and compare exit codes, complete
report digests, published document bytes and Receipt digests. Refusal cases also
check that no successful file pair appears. No macro is executed.

The corpus was migrated on 2026-10-23 from all seven regression suites at the
0.3 release (`3a232f7ef6229d691709fea8ad6d76d2282ba4c8`), after those suites passed
against the new CLI. It retains their actual malformed ZIP/XML, capability,
Word, graph, coverage, saved-plan, Receipt forgery and business combinations.
The old scripts' detailed assertions were run during migration; the corpus
checks exact baseline behavior and is complemented by MoonBit unit tests and
independent Python ZIP/XML/JSON Schema and .NET Open XML validation. It does
not itself provide independent correctness or client compatibility evidence.

Report digests recursively omit **only `tool` release metadata**, sort object
keys using MoonBit String order (length, then code units), preserve array order
and JSON types, and hash compact UTF-8 JSON. During replay, release metadata in
saved JSON inputs is updated to the current prepared-plan tool identifier.
All document bytes, other fields and refusal states remain exact comparisons.
These are reviewed regression expectations, not regenerated automatically by CI.
For a deliberate behavior change, review the corresponding source assertion
and new output before updating the corpus and its provenance hashes.

Inputs derive from the pinned XlsxWriter fixtures (BSD-2-Clause), Apache POI
fixtures (Apache-2.0), and author-created business layouts/images (Apache-2.0).
Their original source URLs, hashes, licenses and notices remain in
`tests/fixtures/{upstream,poi,business}` and `docs/third-party.md`.
Generated bytes are test data, never runtime inputs or a downstream adoption
claim. This development corpus is excluded from the Mooncakes source package.
